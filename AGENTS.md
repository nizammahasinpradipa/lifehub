# Workspace Rules: personal

## File Operations & Permissions
- **Autonomous File Modifications**: Always accept and apply changes to files in this workspace (`d:\PROJECT\personal`) directly.
- **No Confirmation Needed**: Do not ask the user for permission or confirmation before creating, editing, or modifying files within this directory and its subdirectories.
- Execute edits and writes immediately using the appropriate file tools (`write_file`, `edit_file`) or scripts as soon as the task requires it.
- **Scope**: This applies exclusively to files located inside `d:\PROJECT\personal`.
